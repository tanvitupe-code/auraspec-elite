# 🌟 AuraSpec Elite

An ultra-premium, highly responsive digital catalog and analytics comparison matrix tailored for showcasing elite tier flagships, multi-million dollar hypercars, and luxury consumer smartphones.

---

## 🚀 Key Architectural Features

* **Full 22-Product Flagship Database:** Features 11 elite tier smartphones and 11 distinct supercars with perfect image-to-model matching and zero data repetitions.
* **Dual-Tier Smart Filtering Array:** Dynamic navigation sub-pills allowing users to sort high-end vehicles cleanly between **🏎️ Hyper Performance Mode** and **🚗 Daily Premium Cruisers**.
* **Context-Synchronized Comparison Matrix:** Clicking the "Compare" handler on any product card automatically caches that object, switches active tabs, and populates the dual dropdown panels instantly.
* **Live Financial Engine:** Integrated interactive EMI calculator with real-time sliding variables computed dynamically based on premium asset valuations.
* **Fidelity User Review Hub:** Expansive, verified buyer feedback strings seamlessly mapped to each product tier to simulate a lively, highly immersive customer market interface.

---

## 🛠️ Technology Stack

* **Frontend Framework:** React.js (Vite bundling utility)
* **Styling Engine:** Tailwind CSS (Premium Luxury Dark/Glassmorphism theme)
* **Iconography:** Lucide React
* **State Management:** React Context API for flawless cross-component interaction synchronization

## 💻 Local Installation & Initialization

To clone and execute this master build locally on your system, open your terminal and run the following command sequence:

```bash
# Clone the repository
git clone [https://github.com/tanvitupe-code/auraspec-elite.git](https://github.com/tanvitupe-code/auraspec-elite.git)

# Navigate into the frontend root directory
cd auraspec-elite

# Install premium package dependencies
npm install

# Initialize the local development server on Port 3050
set PORT=3050&& npm start
